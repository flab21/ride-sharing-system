# Ride Sharing System (Assignment 5)

MSCS-632-A01, Frenie Labrador

A class-based ride sharing system written twice, once in C++ and once in GNU Smalltalk. Both versions show encapsulation, inheritance, and polymorphism.

## Files

rideshare.cpp is the C++ version.
rideshare.st is the GNU Smalltalk version.

## How to run

C++: g++ -std=c++11 -o rideshare rideshare.cpp
     ./rideshare

Smalltalk: gst rideshare.st
